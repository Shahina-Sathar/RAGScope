# RAGScope component ablation study

**Status: not yet run.** No results have been measured on the full benchmark, so this
file deliberately contains no numbers. Do not quote any metric from this study until
this file is regenerated by the command below.

What is in place:
- Frozen test set: `eval/testset.json`, 100 human-labelled HotpotQA dev questions
  (distractor setting; 70 bridge + 30 comparison; seed 42), not synthetic. Its sha256 is
  in `eval/testset.sha256` and is checked on every run.
- Corpus: 4,951 Wikipedia paragraphs (5,842 chunks), rebuilt by `eval.build_benchmark`
  and indexed into the Pinecone namespace `ablation-hotpotqa-v1`.
- Configurations: C0 vector → C1 +BM25/RRF → C2 +cross-encoder → C3 +LLM rewrite →
  C4 +LangGraph corrective loop, plus C4_legacy (the app's existing CorrectiveRAG).
- Statistics: 95% bootstrap CIs over questions; paired sign-flip permutation tests with
  Holm adjustment.

A 3-question smoke test ran end to end with 0 errors. It only checks that the code
works; 3 questions are far too few for any quality claim.

Running the full study uses the OpenAI API, which is billed separately from a ChatGPT
plan. With gpt-4o-mini as generator and judge, the smoke test's token counts put the
total at about $3–4.

## Reproduce

```bash
(cd backend && uv sync)
mkdir -p eval/data/raw && curl -L -o eval/data/raw/hotpot_qa_distractor_validation.parquet \
  https://huggingface.co/api/datasets/hotpotqa/hotpot_qa/parquet/distractor/validation/0.parquet
backend/.venv/bin/python -m eval.build_benchmark
backend/.venv/bin/python -m eval.run_ablation --configs all --runs 3 --judge-model gpt-4o-mini
```

`run_ablation` overwrites this file with the generated tables when it finishes.
